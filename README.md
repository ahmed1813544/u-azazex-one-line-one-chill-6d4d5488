## What it does

`main.py` (stdlib only) writes exactly one sentence of horror — under 200 characters — to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).

## Run it

```sh
python3 main.py
```

## The line

> The tide returned the boat I sank with my brother in it, and someone was still rowing.

86 characters, one sentence, deterministic — every run writes the identical file.
